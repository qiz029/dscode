# Session footer

右下角按可用宽度显示 `current: ~28.4 tps ｜ average: 3.1 tps ｜ context: 43% ｜ ~$0.0030 ｜ cache 90.0%`，窄窗口优先保留两项 TPS，逐步省略缓存、费用和上下文。

- **current**：当前根 agent 最近 5 秒的输出速率。流式响应只有文本、推理和工具参数增量，尚无逐 token 计数，因此按 UTF-8 字节数 / 4 估算并显示 `~`；每次请求结算后用 provider 报告的精确 outputTokens 校准该会话的估算系数。分母是窗口内实际覆盖的时长（0.5 到 5 秒），输出中断超过 1.5 秒（工具执行、等待首个 token）后下一段输出重新开窗，所以工具调用之后第一秒就是真实速率；停止输出后约 5 秒降至 `0.0`。
- **average**：当前根 session 所有已结算 assistant 输出 token / 这些请求的 LLM 调用总耗时（每步从请求开始到结算，含首个 token 的等待）。工具执行和用户两轮输入之间的空闲不计入；子 agent 的输出不计入；进行中的请求在结算前不计入。若任一消息缺少精确 usage 或对应的步骤开始事件，显示 `--`。
- **context**：当前会话的 token-meter 上下文估算 / 模型上下文窗口，压缩后重新计算。包含当前可见上下文；adapter 临时注入的额外文本不在本地估算中。
- **session**：美元估算，累计当前会话及其子 agent 已记录的模型调用，包括压缩、标题生成和 auto 审核。恢复会话保留累计值；新会话重新计数。模型之外的 MCP/API 服务费用不计入。
- **cache**：累计缓存读取 token / 累计全部输入 token，按 token 加权，不是请求命中率或各请求百分比的平均值。

`~` 表示估算；`+` 表示只有部分费用可计算；`--` 表示数据或价格未知；`…` 表示请求尚未结束。未收到 usage 前不预支本次费用。底栏每秒刷新，无额外模型请求。

`current` 与 `average` 各按自身 TPS 着色：低于 75 为黄色，75 至低于 150 为绿色，150 至 250（含）为蓝色，高于 250 为紫色。未知值 `--` 保持普通颜色；标签与分隔符不随速率变色。

价格采用 [DeepSeek 官方价目表](https://api-docs.deepseek.com/quick_start/pricing/) 的 2026-09-11 快照，按请求开始时间区分峰谷价，仅匹配支持的官方 provider/model。价格更新需更新 `plugins/session-metrics/pricing.mjs`；显示值不是供应商账单。旧会话能从日志补回部分调用，但历史审核/标题/子 agent 用量未必完整，因此标为部分合计。

记录保存在 `$DSH_HOME/session-metrics/`，只含模型、时间、usage 和费用等元数据，不保存提示词或凭据。原始 session 日志不添加自定义事件。
