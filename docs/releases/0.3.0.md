# DSCODE 0.3.0

本次发布包含 0.2.0 之后的登录、终端交互和运行时改进。

- `/login` 使用隐藏输入框保存本地 DeepSeek key，支持启动加载与当前会话重载；环境变量优先。
- effort 横向选择条与 Ultra 动画，欢迎框显示版本、模型和项目路径。
- 输入区固定在终端底部，长对话采用屏内视口；完整内容仍可查看或导出。
- 空白启动先显示输入框，Chrome MCP 在创建 agent 会话时连接。
- 修复 Git 子目录内的 `apply_patch` 路径处理。
- 加强启动与版本管理锁、会话消息处理，并加入压缩评测工具和隔离测试流程。

升级：

```sh
npm install -g @toddzheng024/dscode@0.3.0
dscode update 0.3.0
```

发布验证覆盖本地确定性测试、TUI 渲染、打包和 Hub 安装生命周期。真实远程模型、浏览器和桌面操作不属于此次发布验收范围；中文候选框位置仍需用户终端确认。
