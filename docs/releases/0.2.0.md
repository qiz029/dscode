# DSCODE 0.2.0

This update connects the TUI, CLI, scripts and other agents to one session runtime, and offers a clearer terminal status display.

- Session communication: built-in `list_sessions`, `read_session`, `send_session` and `reply_session`; queue / steer / defer, a persisted mailbox, retry de-duplication, cancellation and a finite communication budget. Only a loaded root session in the same state directory is reachable, and an offline session is never started automatically.
- Descriptive cards: project, workspace and recent user topics; task conclusions are never recorded.
- Global memory: background extraction, consolidation and retrieval with source tracking, plus global and per-session switches. Background extraction causes extra model calls; see the memory documentation.
- Input and resume: `!` shell, Shift+Enter newline, `dscode resume`, a resume hint on exit, and CJK input cursor positioning.
- TUI: a compact header, a unified run status, a sub-agent activity overview and de-emphasised cost/context/cache figures; thinking and tool-call history are hidden by default.
- Ultra: keeps native max reasoning and delegates as the task needs; a parent agent can choose a separate effort for each child.
- Compatibility: the recommended Harness composition is pinned; the npm launcher only prints a warning for another composition and keeps starting.

## Install and upgrade

```sh
npm install -g @toddzheng024/dscode@0.2.0
dscode
```

A user who already has an npm/Hub profile has to run `dscode update 0.2.0` separately. Exit running processes before upgrading; `dscode history` and `dscode rollback` manage profile revisions. A program rollback is not a data-format rollback.

The recommended Harness is still `0.1.5-rc.1` and the upstream TUI is `dsh-code@1.0.6`. macOS 14+, Node 22.19+ (22.x) or 24+ are supported.

## Verification scope

70 regression tests; the real Ink dark and light themes rendered at 32/48/80/120 columns; an isolated TUI launch, CJK text and Shift+Enter; the native session write lock, reads and crash recovery. Before release, a temporary install of the npm tarball separately verified the agent, session communication, cards, memory, a failed upgrade and rollback.

The model integration checks use a deterministic local adapter. Remote model quality, the human experience of the system input-method candidate window, and real browser and desktop control are outside this verification scope. A claimed message cannot be guaranteed recalled.
