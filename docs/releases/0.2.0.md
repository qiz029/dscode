# DSCODE 0.2.0

本次更新让 TUI、CLI、脚本和其他 agent 连接同一个 session 运行时，并提供更清晰的终端状态显示。

- Session 通信：内置 `list_sessions`、`read_session`、`send_session`、`reply_session`；支持 queue / steer / defer、持久化邮箱、重试去重、取消与有限通信预算。只连接同一状态目录中已加载的根 session，不自动启动离线会话。
- 描述性名片：项目、工作区与最近用户 topic；不记录任务结论。
- 全局 memory：后台提取、整理、检索与来源追踪，提供全局和 session 开关。后台提取会产生额外模型调用，参见 memory 文档。
- 输入与恢复：`!` Shell、Shift+Enter 换行、`dscode resume`、退出恢复提示和中文输入光标定位。
- TUI：紧凑头部、统一运行状态、子 agent 活动概览、弱化的费用/context/cache 指标；默认隐藏 thinking 和工具调用历史。
- Ultra：保留原生 max 推理，按任务需要委派；父 agent 可为子 agent 选择独立 effort。
- 兼容性：固定推荐 Harness 组合；npm 启动器遇到其他组合只显示 warning，并继续启动。

## 安装与升级

```sh
npm install -g @toddzheng024/dscode@0.2.0
dscode
```

已有 npm/Hub profile 的用户需另执行 `dscode update 0.2.0`。运行中的进程退出后再升级；可用 `dscode history` 和 `dscode rollback` 管理 profile 修订。程序回退不等于数据格式回退。

推荐 Harness 仍为 `0.1.5-rc.1`，上游 TUI 为 `dsh-code@1.0.6`。支持 macOS 14+、Node 22.19+（22.x）或 24+。

## 验证范围

70 项回归测试；实际 Ink 深浅主题与 32/48/80/120 列渲染；隔离 TUI 启动、中文文本和 Shift+Enter；原生 session 写锁、读取及崩溃恢复。发布前对 npm tarball 的临时安装另验证 agent、session 通信、名片、memory、升级失败与回退。

模型集成检查使用确定性本地 adapter。远程模型质量、系统输入法候选框的人机体验、真实浏览器和桌面操作不属于本次验证范围。已领取的消息无法保证撤回。
