# DSCODE 0.7.12

This release turns `!cmd` shell mode into a real mode (rounded border, `!` flush left, Esc to leave, with the command and its redacted output returning to the agent context), moves the submit default back to steer, and fixes two problems: "the composer drifting up and down on every loop" and "cache hit always showing --".

- Shell mode: when the draft starts with `!` the composer switches to a brand-coloured rounded border (outline only, no fill), `!` sits flush left, and Esc leaves the mode while keeping the command text; outside the box a new `! shell mode · esc exits` hint appears (in 6 languages). After `!cmd` runs, the command and its redacted output return to the agent as context.
- Submit mode is steer again: submitting while a turn runs inserts into the current turn, and while idle it sends normally; Tab now switches to queue (dsh-code 1.2.0 changed the default to queue).
- Frame geometry: Ink's frame redraw is anchored to the bottom — when the live area shrinks, the freed lines stay as blank space above instead of being reclaimed, the redraw block height only grows, and the composer is only pushed down by new output; the persistent activity line and the compaction panel also count against the live-area budget, so the frame cannot reach the terminal height (where Ink clears the screen every frame and wipes the scrollback). `scripts/verify-tui-scroll.mjs` (an ANSI screen simulation) was added as a regression test.
- Cache-hit telemetry is no longer wiped by "an auxiliary call with no usage" (memory, review, an interrupted timeout stream): a missing usage is recorded as unaccounted and only a malformed usage counts as unknown. Of 1707 `end` rows in the local ledger, 49 had no usage, and after the fix that session shows 98.4%.
- IME cursor following is delegated to dsh-code 1.2.0's native anchor (the previous three-line drift is gone); the footer's cache figure is kept from 80 columns (it used to need 130).

Verification: `npm run check` passes (258 unit tests, 44 evaluation tests; integration, the real Ink UI (6 probes, including the new scroll regression) and the package checks pass).
