# DSCODE 0.7.12

这版把 `!cmd` 的 shell 模式做成一个真正的模式（圆角边框、`!` 顶格、Esc 退出，命令与脱敏后的输出回到 agent 上下文），把提交默认值改回 steer，并修掉"输入框随每个 loop 上下漂移"和"cache hit 一直显示 --"两个问题。

- shell 模式：草稿以 `!` 开头时 composer 换成品牌色圆角边框（只描边、不填充底色），`!` 顶格，Esc 退出该模式并保留命令文本；框外新增 `! shell mode · esc exits` 提示（6 种语言）。`!cmd` 执行后命令与脱敏输出作为上下文交回 agent。
- 提交模式回到 steer：回合运行中提交会插进当前回合，空闲时正常发出；Tab 改为切到 queue（dsh-code 1.2.0 把默认值改成了 queue）。
- 帧几何：Ink 的帧重画改为底部锚定——直播区变短时，省下的行作为空白留在上方而不被回收，重画块高只增不减，输入框只会被新输出往下推；常驻活动行与 compaction 面板占用的行也计入 live 区预算，避免帧顶到终端高度（Ink 在那种情况下会每帧清屏并清掉 scrollback）。新增 `scripts/verify-tui-scroll.mjs`（ANSI 屏幕模拟）作为回归测试。
- cache hit 遥测不再被"没有 usage 的辅助调用"（memory、review、中断的超时流）整段清空：缺 usage 记为未记账，只有 usage 畸形才判为未知。本机账本 1707 条 end 行中有 49 条无 usage，修复后该会话显示 98.4%。
- IME 光标跟随交给 dsh-code 1.2.0 的原生锚点（原先的 3 行漂移消失）；footer 的 cache 数字从 80 列起保留显示（此前要 130 列才出现）。

验证：`npm run check` 通过（258 项单测、44 项评估测试；集成、真实 Ink UI（6 个探针，含新增的滚动回归）与安装包检查通过）。
