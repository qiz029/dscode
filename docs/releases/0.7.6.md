# DSCODE 0.7.6

This release expands OpenRouter from three DeepSeek models to pi-ai's whole OpenRouter catalogue, and fixes several things that stopped a non-DeepSeek model from working or made it worse: effort hard-coded to the DeepSeek bands, delegation available only under Ultra, and cost and cache-hit rate that could not be computed. The review output ceiling is no longer squeezed so low either.

- **OpenRouter lists the whole catalogue**: the configuration `/provider openrouter` writes no longer lists 3 DeepSeek models but every OpenRouter model in the pi-ai catalogue (366, including Anthropic, OpenAI, Google, Qwen, Kimi, GLM and more), without adding one by id by hand. The three DeepSeek models still use the official off/low/high/max bands and Ultra through `modelOverrides`, while the other models use their own reasoning bands and protocols (Claude goes through `anthropic-messages`). A narrow configuration written by 0.7.3–0.7.5 is replaced automatically when `/model` is opened or the provider is switched; a configuration the user edited is left alone.
- **`/model` can search**: press `/` or Ctrl+F to start searching, and every word typed has to match a provider or a model name; while searching, `q`, `r` and `g` are only text, Esc exits and clears, and ↑↓ and Enter work as usual.
- **OpenRouter cost is computed from live prices**: with an OpenRouter key configured, prices are read from OpenRouter's public model list (no key needed) and cached in the data directory for a day, including the cache-write price and the long-prompt tiers; a model without a separate cache read/write price is charged at the input price. A failed read keeps the previous prices, and the DeepSeek models still have a fixed price fallback.
- **Fix: the cache-hit rate was always `--` on OpenRouter**: pi-ai reports that number only when there was a cache read, and one call without the field made the whole session's rate unknown; a missing value now counts as 0.
- **Effort follows the model**: the configured default `high` falls back to the model's own default when unsupported, so a model without reasoning (such as qwen3-coder or kimi-k2) no longer errors every turn. Session cards, `/doctor`, memory and review under Ultra request the supported band closest to the wanted one and pass nothing when the model has no bands; the memory configuration accepts every standard band name. `dscode exec --effort` accepts `minimal`, `medium` and `xhigh` and validates them against the model before starting. A child agent's effort text is no longer hard-coded to low/high/max, and `/status` no longer shows xhigh for a non-DeepSeek model.
- **Delegation at any effort**: `subagent` and `subagent_fork` are no longer available only under Ultra, so a model without a `max` band (and therefore without Ultra) can delegate too. Below Ultra the prompt controls it: do the work yourself by default, delegate only a larger independent part or a wide read-only investigation that would crowd the context, at most one child at a time, at the lowest suitable band the model supports. Ultra keeps its original collaboration policy; `workflow` and `ralph` remain unavailable, and the three-child concurrency cap applies at every effort.
- **The review output ceiling is loosened**: it no longer caps at 8192 output tokens but uses the model route's default ceiling (256k for DeepSeek, the model's own in the OpenRouter catalogue); the timeout goes from 90 seconds to 10 minutes, and the report handed back to the agent keeps at most 64,000 characters.

Exit DSCODE sessions using the same data directory before upgrading:

```sh
npm install -g @toddzheng024/dscode@0.7.6
dscode update 0.7.6
```

`dscode-0.7.6.tar.gz` can also be downloaded from GitHub Releases to install the standalone source package; the two installation forms use different data directories and never migrate sessions or credentials automatically.

Verification covers unit, integration, TUI, package build and the coverage baseline. New here:
- In a real Host, the OpenRouter route lists more than 300 models, the DeepSeek models keep the official bands and GPT-5 uses its own; the narrow configuration from 0.7.3–0.7.5 is read back in the shape the settings service actually returns, confirming it is recognised and replaced.
- Requests are intercepted before they go out: qwen3-coder carries no reasoning parameters under the default `high`; a below-Ultra request carries `subagent`; `exec --effort medium` is rejected on DeepSeek Flash and lists the available bands.
- The real Ink `/model` panel is rendered to verify search filtering, `q` not closing the panel while searching, Esc clearing, and Enter selecting.
- Price parsing is checked against a real snapshot of the OpenRouter model list (442 priced models), with tests for tiered prices, cache writes, the one-day cache and an offline restart.
- Patch upgrade tests: a dependency carrying the old patch migrates to the new delegation filtering and child-effort text, and applying it again produces no change.

Not done: no non-DeepSeek model was called with a real OpenRouter key; the real effect of the below-Ultra delegation prompt has not been evaluated.
