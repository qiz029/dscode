# DSCODE 0.7.8

这版修复长任务反复审查、检查通过后仍不断扩展工作的体验，并优化本地会话数据处理。

- 自动代码审查每个用户任务最多两轮，每轮最多 90 秒，每次模型请求最多 8,192 输出 tokens，使用低推理档。换路径、失败或恢复会话不会重新获得完整额度；第二轮聚焦已修问题及其直接回归。未完成审查不会报告为通过，用户仍可主动运行 `/review`。
- 默认 agent 规则要求开工前说明、关键发现时更新，并在长任务中尽量每分钟提供正常正文进度。非 verbose 模式也显示这些内容；阻塞工具可能延迟更新，模型遵循效果仍需真实任务验证。
- 明确任务范围和验收条件，审查意见先核实，修复后运行受影响检查。检查通过后转入交付，不重复扩展可选优化。
- 会话指标增加有界增量读取缓存和 footer 计算缓存；正确处理未换行末行。会话卡片复用内容摘要，记忆任务避免大数组展开。
- mailbox 增加历史保留与按收件人的事件清理，保留待投递消息；测试采用独立小限额，不再写入 5 万条数据。
- OpenRouter 空 SSE 数据过滤及损坏缓存重读节流；构建导入路径校验、补丁公共函数解耦、macOS stdin 探测退避及旧补丁迁移。

本版不升级 DSH 上游依赖。

验证：`npm run check` 通过（226 项单测、44 项评估测试；完整源码覆盖率 80.08%；集成、真实 Ink UI 与安装包检查通过）。进度沟通与任务收敛的实际模型表现仍需真实使用验证。
