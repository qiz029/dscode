# DSCODE 0.6.0

这版聚焦无人值守运行、子 agent 的可读身份和发布体验。

- `dscode exec "prompt"` 在不打开 TUI 的情况下跑完一轮完整的 dscode agent：同一预设、工具、技能、MCP 与记忆。回复流式输出到 stdout，工具活动和 session id 在 stderr，退出码反映轮次结果。支持 stdin 提示词、`--json`、`--resume`、`--effort`、`--model`、`--permission`、`--approve-all` 与 `--timeout`。无人在场时走到人工兜底的审批请求默认拒绝。
- 父 agent 必须给每个子 agent 起名（1 到 10 个字符，英文、数字、下划线，首尾为英文字母）。子 agent 在 agents 行和 `/agents` 中显示为 `/name · description`，`send_message` 与 `interrupt_agent` 接受 `/name`，子 agent 用 `/` 指代父 agent；同一父 agent 下活着的子 agent 不能重名。
- 欢迎框换成三档色阶的像素雪花，26 行以上终端用 24×24，24 到 25 行用 22×22；agent 工作时底部活动行是雪花轨道动画；轮次分割线铺满整行。
- 提示词微调：persona 补充回复语言、判断与提问边界、完整交付和如实汇报的准则；shell 策略只保留委派摘要，细节留在 Ultra 请求策略；邮件引导不再内嵌真实联系人。
- 发布脚本可从 macOS 钥匙串读取 granular npm token，通过一次性临时配置传给 npm，免登录、免验证码；`npm run publish:token store|check|remove` 管理该 token。

升级前退出使用同一数据目录的 DSCODE 会话：

```sh
npm install -g @toddzheng024/dscode@0.6.0
dscode update 0.6.0
```

也可从 GitHub Releases 下载 `dscode-0.6.0.tar.gz` 安装独立源码包。两种安装方式使用不同数据目录，不自动迁移会话和凭据。

验证覆盖单元、集成（含 exec 的假模型端到端探针）、TUI、包构建、真实本机 Harness 启动和 Hub 安装/回退。`dscode exec` 只用一句话对真实模型做过冒烟；子 agent 命名在重启后的旧会话中仅保留显示，`/name` 寻址需要同一进程内创建的子 agent。
