# DSCODE 0.4.0

新增 Agent 邮件系统，支持通过邮件补充当前编码任务的上下文。

- `/email` 展示所有 session 共用的本地收件箱，按更新时间排序，支持中文预览和窄窗口。
- Gmail 应用密码连接 IMAP，接收首次连接后主题以 `[ToAgent]` 开头的新邮件；保留可选 OAuth 接口。
- 选中邮件按 Enter，空闲或运行中均直接注入当前 session。JSON 结构明确标注由用户选择、仅作为补充上下文。
- `send_email` 通过 Gmail SMTP 发送纯文本，自动添加 `[ToAgent]`，复用现有审批及本地凭据，记录发送结果以防重复发送。
- 联系人别名跨 session 共用，可由 agent 或 `dscode email alias` 管理；审批显示真实地址。

升级前退出正在使用同一数据目录的 DSCODE 会话：

```sh
npm install -g @toddzheng024/dscode@0.4.0
dscode update 0.4.0
```

进入 `/email` 后按 `i` 配置 Gmail 地址与应用密码。详情见 [邮件说明](../email.md)。邮箱和联系人保存在 `~/.dscode/email`，不会打入发布包。

验证覆盖确定性测试、真实本机 TLS IMAP/SMTP 协议、TUI 和包安装生命周期。未使用真实 Gmail 发送邮件；SMTP accepted 表示服务端接受，不保证收件人已收到或阅读。发送目前仅支持 Gmail 应用密码连接，不支持附件或自动回复。
