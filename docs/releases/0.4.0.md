# DSCODE 0.4.0

Adds the Agent email system, which lets email add context to the current coding task.

- `/email` shows the local inbox shared by all sessions, ordered by update time, with CJK previews and narrow-window support.
- A Gmail app password connects IMAP and receives new mail whose subject starts with `[ToAgent]` after the first connection; an optional OAuth interface is retained.
- Pressing Enter on a selected message injects it into the current session whether it is idle or running. The JSON structure states explicitly that the user chose it and that it is supplementary context only.
- `send_email` sends plain text through Gmail SMTP, adds `[ToAgent]` automatically, reuses the existing approval and local credentials, and records the send result to prevent a duplicate send.
- Contact aliases are shared across sessions and can be managed by the agent or by `dscode email alias`; the approval shows the real address.

Exit DSCODE sessions using the same data directory before upgrading:

```sh
npm install -g @toddzheng024/dscode@0.4.0
dscode update 0.4.0
```

Inside `/email`, press `i` to configure the Gmail address and app password. Details are in [Email](../email.md). The mailbox and contacts are stored in `~/.dscode/email` and are never put into a release package.

Verification covers deterministic tests, the real local TLS IMAP/SMTP protocol, the TUI and the package install lifecycle. No mail was sent through a real Gmail account; an SMTP accepted means the server accepted it and does not guarantee the recipient received or read it. Sending currently supports only a Gmail app-password connection, with no attachments and no automatic replies.
