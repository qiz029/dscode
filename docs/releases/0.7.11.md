# DSCODE 0.7.11

这版把内置 TUI 从 `dsh-code` 1.0.6 迁到 **1.2.0**，并把前几项改动一起发出。

- **TUI 迁移到 dsh-code 1.2.0**：25 个 DSCODE 补丁全部重新对齐。上游这版改动很大——本地命令目录改成 i18n 的 `descriptionKey`、`Header` 组件整体重写、输入层重构、`/language` 与 `/review` 变成上游自有功能。我们的做法是：命令目录给上游 `t()` 注入回退分支（不改上游消息表，避免未来源码合并时类型冲突），`/language` 与 `/review` 有意识地抢位/整块认领。
- **DSH 固定 `0.1.5-rc.2`**：依赖图与 runtime 补丁闸门同步，9 个 runtime 补丁全部按 rc.2 重新验证（含 macOS stdin 探针）。
- **`dscode update` 一步升级整个安装**：npm/Hub 路径先用 npm 替换 launcher 本体再升 profile；tar 路径下载 release tar 包、校验 sha256、原位换目录并迁移 `.runtime`/`.env`/本地 config；源码检出处拒绝并提示 git pull。另有 TUI 内 `/update`：退出后由 detached 助手自动完成升级。
- **启动检查新版本**：TUI 启动时读一次 npm registry（8 秒超时，失败静默），有新版本时提示 `/update`；`DSCODE_UPDATE_CHECK=off` 可关闭。
- **更新提示支持七种语言**（en/zh-CN/zh-TW/ja/ko/es），启动提示走 TUI 语言运行时，`/update` 跟随已保存语言。
- **`/model` 只列当前 provider 的模型，并按展示名做字母序**（数字自然序，GLM 5.2 在 5.3 前）；搜索只负责筛行、不重排。
- **代码审查更可靠**：输出预算 8k → 32k（推理 token 计入），一次尝试若花光预算却没写出报告，用翻倍预算重试到 64k；默认从模型支持的最低推理档开始；支持 `DSCODE_REVIEW_MODEL=provider/model` 与 `DSCODE_REVIEW_EFFORT=<level>`（对齐 Codex 的 `review_model`）；失败时带上每次尝试的预算与用量诊断。
- **错误显示**：非用户主动取消的意外停止（hook 拦截、restart 中断、blocked）改用错误色，不再以暗色 turn marker 呈现。
- **新工具**：`npm run probe:tui [目录]` 可在升级前 30 秒量化 TUI 补丁的破坏面（本次迁移就是用它驱动的）。

本版不升级 DSH 之外的其它外部依赖（`@anionex/dsh-computer-use`、`chrome-devtools-mcp`、`node-addon-system` 已是各自最新版）。

验证：`npm run check` 通过（258 项单测、44 项评估测试；lint、依赖集成、4 项真实 Ink UI 验证——TUI 渲染/滚动回放/effort bar/model 搜索、安装包检查全部通过）。TUI 迁移期间发现并修复了三类上游行为变化引起的验证问题：`time-context` 注入、`view.pending` 新字段、`recordHistory` 新 prop。
