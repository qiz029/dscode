# DSCODE 0.7.1

This release fixes TUI wheel scrolling and makes the scroll feel finer.

- Fixed the wheel doing nothing: 0.7.0 disabled mouse capture by default, while the TUI redraws in place and clears the terminal scrollback, so with capture off the wheel produced no event and there was no terminal content to scroll; only `/mouse` turned it on. Capture is now on by default and the wheel works out of the box; `/mouse` can still turn it off to drag-select and copy directly.
- One wheel notch now scrolls 1 line (was 3), and wheel events landing in the same 16ms frame are merged into one redraw: a continuous trackpad slide is smoother and fast scrolling no longer drops events.
- The wheel listener registers once and reads the latest state through a ref, cutting the re-render cost per event; PageUp/PageDown behaviour is unchanged.
- The `/mouse` hint now prefers Shift (in terminals such as Ghostty, Shift-drag is the local selection by default), with Option for iTerm2 and Fn for Terminal.
- A bundle that already carries the old patch upgrades in place to the new implementation. The README became English-first with `README.zh-CN.md` retained, and `docs/CHANGELOG.md` was added to record the release history from 0.1.0.

Exit DSCODE sessions using the same data directory before upgrading:

```sh
npm install -g @toddzheng024/dscode@0.7.1
dscode update 0.7.1
```

`dscode-0.7.1.tar.gz` can also be downloaded from GitHub Releases to install the standalone source package. The two installation forms use different data directories and never migrate sessions or credentials automatically.

Verification covers unit, integration, TUI, package build, a real local Harness launch and Hub install/rollback. The TUI end-to-end verification gained assertions for "one wheel notch moves one line" and "three scrolls in the same frame move three lines".
