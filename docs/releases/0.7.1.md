# DSCODE 0.7.1

这版修复 TUI 滚轮滚动，并把滚动手感调细。

- 修复滚轮失效：0.7.0 默认关闭鼠标捕获，而 TUI 原地重绘并清空终端 scrollback，捕获关闭后滚轮既没有事件、也没有可滚动的终端内容，只有 `/mouse` 打开才能滚。现在默认开启捕获，滚轮开箱即用；`/mouse` 仍可关闭以直接拖选复制。
- 每格滚轮改为滚动 1 行（原 3 行），并把落在同一 16ms 帧内的滚轮事件合并为一次重绘：触控板连续滑动更顺滑，快速滚动不再丢事件。
- 滚轮监听器只注册一次并用 ref 取最新状态，减少每个事件的重渲染开销；PageUp/PageDown 行为不变。
- `/mouse` 提示改为 Shift 优先（Ghostty 等终端默认 Shift 拖选即为本地选择），iTerm2 用 Option、Terminal 用 Fn。
- 已打过旧补丁的 bundle 会原地升级到新实现。README 改为英文主版本并保留 `README.zh-CN.md`，新增 `docs/CHANGELOG.md` 记录 0.1.0 起的发布历史。

升级前退出使用同一数据目录的 DSCODE 会话：

```sh
npm install -g @toddzheng024/dscode@0.7.1
dscode update 0.7.1
```

也可从 GitHub Releases 下载 `dscode-0.7.1.tar.gz` 安装独立源码包。两种安装方式使用不同数据目录，不自动迁移会话和凭据。

验证覆盖单元、集成、TUI、包构建、真实本机 Harness 启动和 Hub 安装/回退。TUI 端到端验证新增“一格滚轮移动一行”和“同帧三次滚动移动三行”的断言。
