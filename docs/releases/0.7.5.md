# DSCODE 0.7.5

这版让 review 在非 Git 工作区也能用。评测里 `/app` 不是 Git 仓库，模型从没收到调用 review 的提示，review 工具在那里也只会返回 `no_repository`。

- **非 Git 工作区也有 review 提示和 diff**：任务第一次调用工具之前，dscode 把工作区快照成一棵 tree，存进 `DSH_HOME/review-baselines` 下的影子 bare 仓库（不会动工作区本身）；review 时再快照一次，与基线比出 diff 交给独立审核。模型只能通过工具改文件，所以这个时点拍到的就是任务开始前的状态。这类工作区有单独的提示，说明 review 覆盖的是任务开始以来的改动。`path` 可缩小范围，`staged`、`base`、`commit` 仍需要 Git。
- **快照的范围与上限**：跳过 `.git`、`node_modules`、虚拟环境与缓存目录、review 本来就跳过的敏感文件（`.env`、密钥等）以及超过 4 MiB 的文件，工作区里的 `.gitignore` 也生效；这些文件的改动不会被审核。工作区超过 2 万个文件或 256 MiB 时不拍快照，review 返回 `no_baseline` 并提示不要再调用。
- **基线跟随任务**：基线是每个会话一个 ref，resume 后仍在；同一会话开始新任务时替换旧基线。没有 git 可执行文件时行为不变：不注入提示，review 返回 `no_repository`。

升级前退出使用同一数据目录的 DSCODE 会话：

```sh
npm install -g @toddzheng024/dscode@0.7.5
dscode update 0.7.5
```

也可从 GitHub Releases 下载 `dscode-0.7.5.tar.gz` 安装独立源码包；两种安装方式使用不同数据目录，不自动迁移会话和凭据。

验证覆盖单元、集成、TUI、包构建与覆盖率基线。本次新增：快照 diff 包含修改和新增文件、排除忽略目录/敏感文件/大文件、`path` 缩小范围、Git 范围报错、新 store 实例读回基线、新任务替换基线、超限返回 `no_baseline`；以及工具调用前的钩子建立基线、随后 review 工具审核到改动的端到端测试。未在真实模型会话里确认模型会按提示调用 review。
