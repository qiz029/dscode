# DSCODE 0.5.0

This release focuses on the coding agent's collaboration boundaries, code review and terminal interaction.

- The Ultra main agent can choose `worktree: true` in `subagent` or `subagent_fork`, so a child agent that needs to edit independently starts an isolated checkout from a clean Git `HEAD`. Sharing the directory remains the default; an isolated launch is refused while the main directory has uncommitted changes. A child agent never delegates to another child agent.
- `/review` and the agent's `review` tool start an independent, read-only model review of a named Git diff. After a code change passes its relevant checks the agent reviews once before ending and fixes concrete findings first. The staging area, a base branch, a single commit and a path range are optional; a repeated review of the same diff reuses its result.
- The TUI supports scrolling up through history. The first Ctrl+C during a run interrupts the agent immediately, and a second exits; a long paste collapses to a marker in the composer and expands fully in the conversation after submitting. A pasted image shows a marker such as `[Image 1]`, and several images are supported. A user message is presented with its own background, and turns are separated by a divider.
- An ordinary DeepSeek Flash agent request gets short task-proportional guidance: answer a simple question directly, and for a bounded code change finish the relevant checks and stop. Low, high and max reasoning do not start a child agent; only Ultra can start or wake one.

Exit DSCODE sessions using the same data directory before upgrading:

```sh
npm install -g @toddzheng024/dscode@0.5.0
dscode update 0.5.0
```

`dscode-0.5.0.tar.gz` can also be downloaded from GitHub Releases to install the standalone source package. The two installation forms use different data directories and never migrate sessions or credentials automatically.

Verification covers unit, integration, TUI, package build, a real local Harness launch and Hub install/rollback. No paid model is called; review quality and image clipboard compatibility across terminals still need testing in real use.
