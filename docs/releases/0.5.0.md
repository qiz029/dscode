# DSCODE 0.5.0

这版聚焦编码 agent 的协作边界、代码审查和终端交互。

- Ultra 主 agent 可在 `subagent` 或 `subagent_fork` 中选择 `worktree: true`，让需要独立编辑的子 agent 从干净的 Git `HEAD` 启动独立 checkout。默认仍共享目录；主目录有未提交改动时拒绝隔离启动。子 agent 不会再委派其他子 agent。
- `/review` 与 agent 的 `review` tool 对指定 Git diff 发起独立、只读模型审查。编码改动通过相关检查后，agent 会在结束前审查一次，并先修复具体发现。可选暂存区、基准分支、单次提交和路径范围；相同 diff 的重复审查复用结果。
- TUI 支持向上滚动历史。运行时首次 Ctrl+C 立即中断 agent，再按一次退出；长文本粘贴在输入区折叠为标记，提交后对话里完整展开。图片粘贴显示 `[Image 1]` 等标记，支持多张图片。用户消息另用背景呈现，不同轮次之间有分割线。
- DeepSeek Flash 的普通 agent 请求获得按任务比例工作的简短引导：简单问题直接回答，有限代码改动完成相关检查后结束。低、高、最大推理档不启动子 agent；Ultra 才能启动或唤醒子 agent。

升级前退出使用同一数据目录的 DSCODE 会话：

```sh
npm install -g @toddzheng024/dscode@0.5.0
dscode update 0.5.0
```

也可从 GitHub Releases 下载 `dscode-0.5.0.tar.gz` 安装独立源码包。两种安装方式使用不同数据目录，不自动迁移会话和凭据。

验证覆盖单元、集成、TUI、包构建、真实本机 Harness 启动和 Hub 安装/回退。不调用付费模型；审查质量、图片在不同终端的剪贴板兼容性仍需实际使用检验。
