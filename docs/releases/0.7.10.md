# DSCODE 0.7.10

这版修复 `dscode --version` 在 tar 与源码安装上的输出版本。

- `dscode --version`（以及 `-v`）现在输出 DSCODE 自身的版本号。此前这两个参数会被透传给 DSH CLI，打印的是运行时版本 `0.1.5-rc.1`，与本版号无关，容易误导排查。npm/Hub 启动器原本就正确输出 launcher 版本。
- 顺带把 `dscode --version` 加进 README 的命令示例。

本版不升级 DSH 上游依赖，也不改变安装或升级行为。

验证：`npm run check` 通过（244 项单测、44 项评估测试；集成、真实 Ink UI 与安装包检查通过）。
