# DSCODE 0.7.10

This release fixes the version printed by `dscode --version` on tar and source installations.

- `dscode --version` (and `-v`) now prints DSCODE's own version number. These two flags used to be passed through to the DSH CLI, printing the runtime version `0.1.5-rc.1` instead, which has nothing to do with this version number and easily misleads troubleshooting. The npm/Hub launcher already printed the launcher version correctly.
- The README's command examples gained `dscode --version` along the way.

This release does not upgrade the upstream DSH dependencies and does not change install or upgrade behaviour.

Verification: `npm run check` passes (244 unit tests, 44 evaluation tests; integration, the real Ink UI and the package checks pass).
