# DSCODE 0.7.0

This release focuses on the everyday feel inside the terminal: language, copying, a visible thinking process, accurate rates, and a steadier review.

- `/language` switches the interface language: English (default), Simplified Chinese, Traditional Chinese, Japanese, Korean, Spanish. With no argument it opens an up/down selection panel, and with an argument it sets the language directly, accepting codes, names and common aliases. The choice is saved in `~/.dsh/dsh-code/language.json`, and `DSCODE_LANGUAGE` overrides it temporarily. The activity line, the agents line, welcome-box labels, footer telemetry labels, the composer placeholder, the various hints and the doctor report are all translated with it.
- Mouse capture is off by default, so the terminal can drag-select and copy directly and PageUp/PageDown scrolls the conversation; `/mouse` turns wheel scrolling on, with the choice saved on this machine.
- `/verbose` (or Ctrl/Alt+R) shows each step's `· Thinking:`, `· Tool Call:` and `Output:` in a dim colour with a blank line between blocks; thinking shows at most 8 lines and hints at Ctrl+O for the full history; the switch is saved on this machine.
- While the agent works the conversation area no longer reserves a fixed third for history: the live content takes only the lines it actually needs and history gets the rest. The busy line is a two-dot comet orbiting a snowflake that breathes with the orbit; the welcome box's pixel snowflake has an inward-to-outward ripple, following the `/animation` setting.
- The footer's `current` is computed from the generation time the window actually covers, so the first second after a tool call is a real rate, and it is calibrated with the exact outputTokens from each settled request; `average` became output tokens / total LLM call time, excluding tool execution and idle time. TPS colouring recognises labels in any language.
- The review tool returns `no_repository` in a non-Git workspace and no longer injects the review guidance; when a model finishes with a reason other than stop it retries once and then reports the provider's reason if it still fails; hitting the output ceiling returns partial rather than a failure, and the ceiling is raised to 8192; a review request no longer counts towards the live TPS.
- Release chain: the dsh-hub CLI is upgraded to 0.3.0 and calls the Hub's sync interface before a profile publish to pull the npm package immediately; the npm publish token is stored in the keychain through `pbpaste | npm run publish:token store`.

Exit DSCODE sessions using the same data directory before upgrading:

```sh
npm install -g @toddzheng024/dscode@0.7.0
dscode update 0.7.0
```

`dscode-0.7.0.tar.gz` can also be downloaded from GitHub Releases to install the standalone source package. The two installation forms use different data directories and never migrate sessions or credentials automatically.

Verification covers unit, integration, TUI, package build, a real local Harness launch and Hub install/rollback. The interface translations were proofread by hand for English and Chinese; the other four languages have not been reviewed by native speakers.
