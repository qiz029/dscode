# DSCODE 0.7.0

这版聚焦终端里的日常手感：语言、复制、可见的思考过程、准确的速率，以及更稳的审查。

- `/language` 切换界面语言：英文（默认）、简体中文、繁體中文、日本語、한국어、Español。不带参数打开上下选择的面板，带参数直接设置，接受代码、名称和常见别名。选择保存在 `~/.dsh/dsh-code/language.json`，`DSCODE_LANGUAGE` 可临时覆盖。活动行、agents 行、欢迎框标签、底栏遥测标签、输入框占位符、各类提示和 doctor 报告都随之翻译。
- 鼠标捕获默认关闭，终端里可以直接拖选复制，PageUp/PageDown 滚动对话；`/mouse` 打开滚轮滚动，选择保存在本机。
- `/verbose`（或 Ctrl/Alt+R）以暗色显示每一步的 `· Thinking:`、`· Tool Call:` 和 `Output:`，块与块之间空一行，思考最多显示 8 行并提示 Ctrl+O 查看完整历史；开关保存在本机。
- agent 工作时对话区不再固定给历史三分之一：实时内容只占实际需要的行数，其余全给历史。忙碌行是一颗绕雪花公转的双点彗星，雪花随轨道呼吸；欢迎框的像素雪花有由内向外的涟漪，跟随 `/animation` 设置。
- 底栏 `current` 按窗口实际覆盖的生成时长计算，工具调用后第一秒即为真实速率，并用每次请求结算的精确 outputTokens 校准估算；`average` 改为输出 token / LLM 调用总耗时，不含工具执行和空闲。TPS 着色识别任意语言的标签。
- review 工具在非 Git 工作区返回 `no_repository` 且不再注入审查引导；模型以非 stop 原因结束时自动重试一次，仍失败则给出 provider 的原因；命中输出上限时返回 partial 而非失败，上限提高到 8192；审查请求不再计入实时 TPS。
- 发布链路：dsh-hub CLI 升级到 0.3.0，profile 发布前调用 Hub 的 sync 接口立即同步 npm 包；npm 发布 token 通过 `pbpaste | npm run publish:token store` 存入钥匙串。

升级前退出使用同一数据目录的 DSCODE 会话：

```sh
npm install -g @toddzheng024/dscode@0.7.0
dscode update 0.7.0
```

也可从 GitHub Releases 下载 `dscode-0.7.0.tar.gz` 安装独立源码包。两种安装方式使用不同数据目录，不自动迁移会话和凭据。

验证覆盖单元、集成、TUI、包构建、真实本机 Harness 启动和 Hub 安装/回退。界面翻译由人工校对英文和中文，其余四种语言尚未经母语者审校。
